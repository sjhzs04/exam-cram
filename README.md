# Exam Cram 考试速成教练

适合临近期末、补考或资格考试、复习时间有限的中文 Codex 技能。它可以根据真题、课件或笔记梳理课程骨架、给考点排序、安排冲刺时间，并通过边讲边考和错题回顾生成考前速记页。

## 安装

1. 从 [GitHub Releases](https://github.com/sjhzs04/exam-cram/releases/latest) 下载 `exam-cram.skill`。这是 ZIP 格式的安装包，可以用解压工具打开。也可以直接下载仓库中的 [exam-cram](exam-cram) 目录。
2. 将完整的 `exam-cram` 文件夹放入 Codex 用户技能目录 `~/.codex/skills/`。确认 `exam-cram/SKILL.md` 与 `exam-cram/references/` 都在。
3. 在 Codex 中开启新一轮对话，输入下面的示例。

> 用 $exam-cram 帮我突击电路期末。我还有 3 天，每天能学 2 小时，手头有课件和一套真题，目标是及格。
